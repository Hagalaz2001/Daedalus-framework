# Why use Daedalus instead of starting from scratch?

Every app needs the same groundwork before the first real feature: sign-in, a database, a design system, the first
screens, tests, safety checks and a way to publish. Daedalus gives you that groundwork, already connected and
checked, so you start on the part that is special about your product.

## From scratch or with Daedalus

| Task | From scratch | With Daedalus |
|---|---|---|
| Website, phone app and desktop app | Three separate projects to set up and keep in step | Made together from one plan |
| Sign-in and accounts | Choose, build and secure it yourself | Included and tested |
| Database and server | Design and wire it up | Included, connected to every app |
| Look and feel | Decide colours, fonts and spacing for each app | One set of choices shared by every app, light and dark |
| First screens | Draw and build each one | Ready-made sign-in, lists, forms, settings and more, with empty and error states |
| Tests and safety checks | Added later, if at all | On from the first day, one command runs them all |
| Publishing | Build a pipeline | A working starting point |
| Working with AI assistants | Each assistant guesses your structure | Clear rules and structure the assistants follow, so the work is easier to review |
| A new teammate | Learns by reading the code | Reads the docs; every project follows one way of working |

## Why this helps

- **You skip the groundwork.** The setup every app needs is done, so your first day goes to your own idea.
- **Fewer surprises.** The pieces are already wired together and tested as a whole.
- **Your apps stay consistent.** One plan and one set of design choices keep the website, phone app and desktop app
  in step. Change something once and the others follow.
- **Quality is built in, not bolted on.** Safety and quality checks run from the start.
- **AI works better with structure.** Assistants make less mess when the project has clear folders and rules, and
  people can review what they produce.
- **Easy to hand over.** The project is documented and follows one way of working.
- **You own everything.** The code is yours and you can change any of it. It is a starting point, not a cage.
- **Free and open source.** Anyone can read it, use it and improve it.

A measured example, from one run on a normal Windows PC: creating a project with a web app, a phone app and a server
took about 41 seconds, and its full check (tests, safety scans and builds) passed in about 4 minutes. Your times will
differ with your computer and network.

## When not to use it

Daedalus is not the right tool for everything. Skip it if:

- you are building a tiny one-page site: a plain page or a simple site builder is simpler;
- you are running a quick throwaway experiment: the structure will feel like overhead;
- your project must use a different technology than the ones Daedalus supports.

## What it does not do

AI can make mistakes. Daedalus keeps a person in charge and runs checks, but you are responsible for what you ship.
