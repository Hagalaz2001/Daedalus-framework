Apps come and go. Notes should not.

Underneath, each note is plain text with light Markdown. That choice limits what we can build, and we think the limit is worth it.

## What you get

1. **Export without friction.** One click gives you a folder of `.md` files.
2. **Longevity.** A text file opens in any editor, today and in twenty years.
3. **Speed.** Plain text is tiny, so search and sync stay quick.

## What you give up

No embedded spreadsheets, no drag-and-drop canvas. If you need those, other tools do them well. We would rather be the place your thoughts live safely.

```
notes/
  2026-09-12-plain-text.md
```

That is the whole format.
