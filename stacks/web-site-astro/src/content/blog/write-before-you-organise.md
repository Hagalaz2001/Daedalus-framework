Most note apps invite you to build a system before you have written anything. A folder tree, a tagging scheme, a template for every occasion. It feels like progress, and it quietly becomes the work.

We kept watching the same pattern: people capture in a hurry, never revisit the structure, and later find things by remembering a word they typed. **The word is the index.**

## What we do instead

- Capture in one keystroke, with no choices to make.
- Let search do the filing. Results appear as you type, with the matching line in context.
- Keep dates visible, because "last Tuesday" is how people actually remember.

## A small test

Open your notes and try to find something from three weeks ago. If you reach for a folder, the system is helping you. If you reach for the search box, it is the search that matters, so make that part excellent.

> The best filing system is the one you never have to maintain.

If you want to try the approach, start with a single list and add structure only when it hurts.
