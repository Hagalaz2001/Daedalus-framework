# Third-party items in the email module

| Package          | Licence | Used for                              |
| ---------------- | ------- | ------------------------------------- |
| nodemailer       | MIT-0   | SMTP transport                        |
| react-email      | MIT     | HTML email components and renderer    |
| react, react-dom | MIT     | rendering the templates on the server |

Resend is called through its public HTTP API with `fetch`; no SDK is bundled.
