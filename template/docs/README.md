# docs

| File | Content |
|---|---|
| `ARCHITECTURE.md` | Layers, feature modules, boundaries, error handling, tests, naming |
| `AI-WORKFLOW.md` | How people and AI agents work together; briefing and review checklists |
| `adr/` | Architecture decision records (`0000-template.md` to copy) |
| `QA.md` | Bug log in terms of what a user would see |
| `REPORT.md` | Plain-language milestone updates |
| `CATALOG.md` | Vetted open-source projects to reuse (copied from Daedalus) |

Other documents (`DATABASE.md`, `MODULES.md`, `OPERATIONS.md`, `diagrams/`) appear when the backend and modules are
present. Decisions get an ADR; specs and audits get one file per topic.
